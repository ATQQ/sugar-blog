# 安利一下最近用的T3 Code

**https://t3.codes/**

![](https://cdn.upyun.sugarat.top/mdImg/sugar/089fe63be46a511841e309ed82e3456c)

T3 Code **不是一个新的 code agent**。只负责把机器上常用的编码 Agent 放到一个界面里管理。

目前支持 Claude Code、Codex、Cursor、OpenCode、Grok、Antigravity

![](https://cdn.upyun.sugarat.top/mdImg/sugar/81ea1114ea2882b54a824da72a662349)

支持桌面端，Web，移动端（iOS/Android）

![](https://cdn.upyun.sugarat.top/mdImg/sugar/27cb9542dc325968822fe95ad1ff50cf)

移动端灵动岛&通知也是有的。
![](https://cdn.upyun.sugarat.top/mdImg/sugar/ad8d4e35e9e313f8b2b4526016b3102b)

*遥遥领先笔者做的多Agent 操作 Demo项目（https://github.com/ATQQ/AgentCodePilot） ☺️*

## 远程控制

笔者常用 Cursor（官方订阅）, Codex, Claude Code （中转）

想要远程 Vibe Coding 比较麻烦，之前的组合。Cursor 只有iOS客户端。

用 T3 的话，同 WIFI 可以走局域网连接，外网可以走官方的账号的登录即可。

![](https://cdn.upyun.sugarat.top/mdImg/sugar/3ef97a327f4621cc11bfae2f07298094)

这样也是非常低能耗，针对不需要一直盯的vibe项目，可以关掉显示器去玩手机。

![](https://cdn.upyun.sugarat.top/mdImg/sugar/84100799724b3c249e67005d9eae2232)

## 体验

体感上还是很流畅的和用各家的客户端差不多，功能都是比较完备的。

不过目前还没有支持中文，没有习惯英文操作界面的话可能上手有点不太适应。

## 最后
有多 Agent 控制，远程 Vibe Coding 的用户可以试试这个项目。

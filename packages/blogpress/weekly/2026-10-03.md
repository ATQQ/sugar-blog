## 🔥强烈推荐
### [1. page-mascot](https://github.com/nilbuild/page-mascot) - 灵动的鼠标跟随宠物

头像会自动跟随鼠标转动，点击也有不同的反馈。

![](https://cdn.upyun.sugarat.top/mdImg/sugar/daa0c7bca5eef73254b8c21490efad4f)

原理是一张精灵图 + 一个封装好的Web组件。

![](https://cdn.upyun.sugarat.top/mdImg/sugar/58ead09a940546d6dace6c09432284d7)

如果你是自己开发Web应用想加个交互的宠物的话可以考虑使用这个组件。

也可以自己用SKILL 定制。

```sh
npx skills add nilbuild/page-mascot --skill page-mascot --global --yes
```

我基于已有的参考图做的。

![](https://cdn.upyun.sugarat.top/mdImg/sugar/2dbc58627f38fad30d86b1e621e842a5)

*转向那张做的不太好，模型拉了！*

### [3. Web 常用音效合集](https://www.soundcn.xyz/?category=UI)

### [8. Vite+ 1.0 发布](https://voidzero.dev/posts/announcing-vite-plus-1-0)

新机配环境可以直接用这个，新项目可以试试了。

![](https://cdn.upyun.sugarat.top/mdImg/sugar/c91bb3e71947f9468265ebaa4b6433ce)

一条 `vp` 命令即可覆盖常见开发流程：
* Node版本管理(`vp env`)
* 包管理器自动识别(`vp install`)
* 开发服务器(`vp dev`)
* 代码检查、格式化、测试、构建和任务执行等

存量的 Vite Vitest ESLint、tsup 可以直接 `vp migrate` 迁移。

## 📚教程&文章
### [9. 为什么习惯 3000 和 8080 作为开发端口](https://smarmelling.com/posts/the-accidental-history-of-3000-8080-and-other-port-numbers.html)
省流：第一个人随手一选 + 后来者理性跟随

比如搞JAVA开发时用 Tomcat 默认端口就是 8080，后面JAVA 系的其它服务也用这个端口作为默认端口。

Ruby 普及了 3000 端口。

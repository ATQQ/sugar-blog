### [2. 不要让 AI 代表你](https://www.ruanyifeng.com/blog/2026/10/weekly-issue-417.html)

**阮一峰大佬这期的观点我非常认同**

> 你可以用 AI 帮助自己学习和工作，但不要让它代表你。

> AI 的行为模式是循环尝试，会穷尽所有可能的方式，尝试完成你交给它的任务，而且这样一遍遍的尝试，对 AI 来说几乎不产生成本。

**真实的社交活动的容错空间很小，不会有穷尽的尝试方式。**

## 🔧开源工具&技术资讯
### [4. Overgrown](https://github.com/charliegerard/Overgrown) - 页面长草了

一个有趣的 Chrome 插件，标签页搁太久，页面上就会慢慢长出藤蔓。

![](https://cdn.upyun.sugarat.top/mdImg/sugar/c5ec5ebbcb53b1c3879bb12bea32a180)

### [5. TitleArt](https://titleart.dvy.io/) - 浏览器里的 WordArt

以前 Word 里那些扭曲、立体、渐变的美术字，被完整搬到了浏览器里。

![](https://cdn.upyun.sugarat.top/mdImg/sugar/adb1207e9798964dc597417f3cab6f06)

### [6. Swarm Rebuild](https://github.com/DhvanilPatel/swarm-cursors) - 炫酷的多鼠标搭建页面效果

一款 Chrome 扩展程序，它可以把任意网页清空成空白画布，模拟多名用户的光标实时协作重建页面的效果。

![](https://cdn.upyun.sugarat.top/mdImg/sugar/af5052bb94c0d73c72edc1ce76408186)

### [7. 非官方的红果SDK](https://github.com/beilunyang/openhongguo)

人人都可以手搓自己的红果客户端了。

提供 Go、Node.js、Android、iOS、React Native 和 Flutter 版本。

### [8. HTML-in-Canvas](https://developer.chrome.com/blog/html-in-canvas)

Chrome 157 稳定版带来了酝酿已久的 HTML-in-Canvas API：可以把真正可交互的 HTML，画进 2D、WebGL 和 WebGPU 的 canvas 里。

![](https://cdn.upyun.sugarat.top/mdImg/sugar/d750856010051c4562a5f8b36732cccc)

*目前还是 Chrome Only，不过对 canvas 重度 页面来说 是个好消息。*

### [9. halfsize](https://github.com/YKLovePython/halfsize) - 将视频压缩到指定大小的工具

```sh
npx halfsize wedding.mp4 --to 25mb
```
CLI 工具一行指令调用搞定

### [10. Site Seeing](https://lab.ishadeed.com/tools/site-seeing/) - 响应式开发适配工具

在线测试各种场景下的网页预览效果工具。

![](https://cdn.upyun.sugarat.top/mdImg/sugar/e031a06d8634c7dc6967e571279f8e09)

覆盖多场景：屏幕键盘弹起来、分屏、DevTool 打开 等等

收藏了⭐️，做页面适配的时候能用上，这个确实很完备。

### [11. UI SFX](https://uisfx.com/) - 930+ 页面音效

78 种 UI 提示音（点击、开关、成功、加购、加载循环……），12 套可切换风格。

![](https://cdn.upyun.sugarat.top/mdImg/sugar/8c595dd98fa1611980f12633618dd493)

给交互加反馈，可以试试。

### [12. chrome-capture](https://github.com/paulirish/chrome-capture) - 把 Chrome 标签页录成 MP4

一条 `npx` 就能把当前标签页按 60–120fps 录成带音频的 MP4。

录 Demo、录 Bug 复现，挺方便。

```sh
npx chrome-capture https://sugarat.top demo.mp4 4s
```
*需要 Chrome 153+ 版本*

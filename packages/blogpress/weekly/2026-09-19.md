### [12. await fetch 在等什么](https://blog.gaborkoos.com/posts/2026-09-08-Half-Past-Fetch/)

```ts
const response = await fetch(url) // awaits the headers
const body = await response.json() // awaits the body
```

`await fetch(url)` 看起来是等待响应的，但实际上它只是等待头部信息。
